# Portfolio

Bienvenue sur le dépôt de mon portfolio personnel. Ce site web présente mon parcours, mes compétences ainsi que les différents projets (académiques et personnels) sur lesquels j'ai eu l'opportunité de travailler.

## Arborescence du projet

```text
portfolioV2/
├── index.html                   # Page d'accueil principale
├── about.html                   # Page À propos (présentation)
├── projects.html                # Vue d'ensemble des projets
├── contact.html                 # Page de contact
├── debrief.html                 # Page de débrief/conclusion
├── readme.md                    # Documentation du projet
├── styles.css                   # Feuille de style globale
├── image/
│   └── logos/                   # Ressources graphiques et logos
├── projets/
│   ├── index/                   # Catégories de projets (BUT1, BUT2, BUT3, persos, etc.)
│   └── details/                 # Pages détaillées pour chaque projet (Dataviz, QGIS, PySpark...)
├── script/
│   └── main.js                  # Scripts JavaScript pour l'interactivité
└── telechargements/             # Ressources et scripts téléchargeables (ex: Python, Jupyter)
```

## Technologies utilisées

- **HTML5 / CSS3** pour la structure et le design du site.
- **JavaScript** pour l'interactivité et la dynamique des pages.
- Diverses ressources liées aux données (**Python**, **Jupyter Notebook**, **SQL**) partagées dans les projets spécifiques.
