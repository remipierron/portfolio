Webscrapping API Python Postman
👥 Projet mené en groupe de 4 📅 Novembre 2024 🏛️ IUT de Poitiers — Niort

Web Scrapping et API

Quel était l'objectif de notre travail ?

Ce projet s'est décomposé en deux parties. Le but de la première partie était de scrapper un site web pour en extraire les données afin de les analyser. La seconde partie, complètement dissociée, visait à parcourir une API pour en extraire des données. Il s'agissait de l'API de l'ADEME (Agence de l'Environnement et de la Maîtrise de l'Énergie) qui permet d'accéder à des données sur les consommations d'énergie et les émissions de gaz à effet de serre des logements en France.

Comment avons-nous procédé ?

J'ai personellement travaillé sur la partie API. J'ai utilisé Postman pour tester l'API de l'ADEME et comprendre comment elle fonctionnait. Ensuite, j'ai utilisé Python pour écrire un script qui interrogeait l'API et récupérait les données.

Quelles difficultés ai-je rencontrées ?

Nous avons rencontré des difficultés pour parcourir l'API, car il y avait plusieurs pages de données à traiter. Heureusement, nous avons réussi à gérer ce problème.

Quelles sont mes compétences acquises ?

J'ai appris à utiliser Postman pour tester des API et à écrire des scripts Python pour interagir avec elles. J'ai également acquis de l'expérience dans le web scrapping et l'analyse de données.

Quelle note avons-nous obtenu ?

Notre travail a été noté 16/20.
