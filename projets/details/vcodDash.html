Projet mené en groupe de 3 - Septembre 2025

Application Python Dash d'annotations d'images

Python Dash Github Hugging Face
👥 Projet mené en groupe de 3 📅 Septembre 2025 🏛️ IUT de Poitiers — Niort

Concevoir une application web avec Dash.

Quel était l'objectif de notre travail ?

Le but de ce projet était de créer une application web permettant d'annoter des images en utilisant la bibliothèque Dash de Python. L'utilisateur devait pouvoir encadrer des voitures sur un jeu d'images et sauvegarder les annotations dans un fichier JSON.

Quelles difficultés avons-nous rencontrées ?

L'une des principales difficultés a été de gérer les interactions utilisateur avec les images, notamment la sélection et le dessin des cadres autour des voitures. Nous avons également dû nous familiariser avec Dash, ce qui a nécessité un certain temps d'apprentissage. Enfin, la gestion de l'état de l'application pour sauvegarder les annotations a été un défi technique intéressant.

Quelles sont mes compétences acquises ?

Au delà de mes compétences acquises avec Dash, j'ai surtout travaillé sur une fonctionnalité de l'application ayant pour but de prédire automatiquement les cadres autour des voitures en utilisant un modèle pré-entraîné disponible sur Hugging Face (Faster R CNN). J'ai aussi utilisé d'autres modèles pour reconnaitre les marques des voitures (CarVit), et aussi pour reconnaitre et lire les plaques d'immatriculation (YoloV8 et TrocR). Cela m'a permis de me familiariser avec l'intégration de modèles de machine learning dans une application web.

Quelle note avons-nous obtenue ?

Notre travail nous a valu la note de 17/20.
