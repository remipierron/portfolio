Projet mené en groupe de 4 - février 2025

SAE / Développement d'un composant d'une solution décisionnelle

PYTHON SQL DOCKER DESKTOP React JS MySQL DBeaver
👥 Projet mené en groupe de 4 📅 février 2025 🏛️ IUT de Poitiers — Niort

Concevoir un logiciel permettant de mettre en place une API à partir d'un jeu de données volumineux

Quel était l'objectif de notre travail ?

L'objectif de notre travail était de mettre en place une API à partir d'un jeu de données très volumineux. Nous avons dû concevoir un logiciel avec Docker Desktop, permettant de gérer quatres conteneurs : un pour l'API, un pour la base de données MySQL, un pour le serveur et un pour l'interface utilisateur.

Comment avons-nous procédé ?

Nous avons commencé par analyser le jeu de données et définir les besoins fonctionnels de l'API. Ensuite, nous avons utilisé Python pour développer l'API. Nous avons également utilisé MySQL pour stocker les données et Docker Desktop pour gérer les conteneurs. Enfin, nous avons créé une interface utilisateur avec React JS pour permettre aux utilisateurs d'interagir avec l'API.

Quelles difficultés avons-nous rencontrées ?

Nous avons rencontré plusieurs difficultés, notamment la gestion de la volumétrie des données et l'intégration des différents composants du système. La configuration de Docker Desktop pour faire fonctionner tous les conteneurs ensemble a également été un défi. De plus, nous avons dû nous familiariser avec les différentes technologies utilisées, ce qui a nécessité un temps d'apprentissage supplémentaire.

Quelles sont mes compétences acquises ?

J'ai acquis des compétences en développement d'API avec Python, en gestion de bases de données avec MySQL et en utilisation de Docker Desktop pour la gestion des conteneurs.
