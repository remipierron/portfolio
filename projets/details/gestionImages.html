📡 Mission no"3" : Automatisation de gestion d'images par API

Le but de ce projet était de concevoir un logiciel permettant le transfers automatisé des images d'un dossier local vers un serveur distant via une API. Ces images s'affiches sur les tablettes de réassorts des boutiques, et permettent d'indiquer visuellement les produits à réassortir. Cela a permis de gagner du temps et de réduire le risque d'erreurs.
