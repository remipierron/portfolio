Suivi de Plantes d'Intérieur

Il s'agit d'une application de répertoire botanique qui permet de recenser, d'identifier et de suivre les plantes de son intérieur. Les végétaux photographiés sont identifiés automatiquement à l'aide de l'API Pl@ntNet et sont stockés localement dans une base de données SQLite unique (images incluses), ce qui rend le projet entièrement portable.

Quel était l'objectif de mon travail ?

L'objectif était de créer une application permettant de cataloguer et d'identifier facilement les plantes d'intérieur à partir de simples photos. Elle s'appuie sur l'API de reconnaissance d'images Pl@ntNet pour obtenir le nom commun et scientifique de chaque plante, et sur une base de données SQLite pour centraliser l'historique, les notes et les dates d'acquisition. J'ai utilisé Streamlit pour construire une interface web simple et conviviale, avec une galerie permettant de visualiser sa collection et de suivre l'évolution de chaque plante grâce à plusieurs photos dans le temps. Les images sont compressées via Pillow et stockées directement en BLOB dans la base SQLite afin de limiter la taille du fichier et de garder tout le projet portable dans un seul fichier.

Quelles sont mes compétences acquises ?

Ce projet m'a permis de renforcer mes compétences en développement d'applications web avec Streamlit, en gestion de bases de données avec SQLite (notamment le stockage d'images en BLOB), et en intégration d'API externes de reconnaissance d'images avec Pl@ntNet. J'ai également travaillé le traitement et la compression d'images avec Pillow, ainsi que la gestion de configuration et de secrets via des variables d'environnement (python-dotenv). Enfin, j'ai amélioré mes compétences en gestion de projet et en documentation, en veillant à ce que le code soit bien structuré et facile à comprendre pour les futurs utilisateurs ou développeurs.
